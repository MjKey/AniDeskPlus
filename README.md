**AniDesk Plus** — форк десктопного клиента **AniDesk** для сервиса **Anixart**.
Проект значительно расширяет функциональность оригинального клиента: от автоматического пропуска опенингов и апскейла Anime4K до полной интеграции с Shikimori и скачивания серий.

### ( 📥 ) Загрузка серий
Скачивайте любимые эпизоды напрямую на локальный диск. Поддерживается выбор источников (`Kodik`, `AniLibria`, `Sibnet`), выбор качества (1080p / 720p / 480p) и сохранение с понятным именем файла.

### ( 🌸 ) Интеграция с Shikimori
- Авторизация через официальный OAuth2.
- Автоматическая синхронизация статусов просмотра (*Смотрю*, *Просмотрено*, *В планах*, *Брошено*).
- Автоматическое обновление просмотренных серий при проигрывании в плеере.
- Выбор домена API (`shikimori.io`, `shikimori.me`, `shikimori.one`) и авторефреш просроченных токенов.

### ( ⏩ ) Умный автопропуск OP/ED
- Автоматическое определение таймингов опенингов и эндингов из баз **AniSkip**, **AniLibria** и плеера **Kodik**.
- Отображение полупрозрачных цветовых сегментов опенинга/эндинга прямо на шкале прогресса.
- Настраиваемые уведомления и плавный пропуск.

### ( ✨ ) Апскейлер видео Anime4K
Встроенные WebGPU-шейдеры **Anime4K** повышают чёткость и качество изображения аниме в реальном времени без нагрузки на CPU.

## ( 📦 ) Установка и запуск

### Готовые сборки
Самые свежие установочные файлы `.exe` доступны на странице [**Releases**](https://github.com/MjKey/AniDeskPlus/releases).

### Сборка из исходников

Для самостоятельной сборки потребуется [Node.js](https://nodejs.org/) (v18+) и [Git](https://git-scm.com/):

```bash
# 1. Клонирование репозитория
git clone https://github.com/MjKey/AniDeskPlus.git
cd AniDeskPlus

# 2. Установка зависимостей
npm install

# 3. Запуск в режиме разработки
npm run dev

# 4. Сборка готового дистрибутива
npm run buildAndMake
```
