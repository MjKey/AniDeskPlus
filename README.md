# AniDesk Plus

[![Version](https://img.shields.io/github/v/release/MjKey/AniDeskPlus?color=blue&label=version)](https://github.com/MjKey/AniDeskPlus/releases)

[![Svelte](https://img.shields.io/badge/Svelte-5.x-FF3E00.svg)](https://svelte.dev/)

**AniDesk Plus** — форк десктопного клиента **AniDesk** для мобильного сервиса **Anixart**.
Проект расширяет базовый функционал оригинального клиента: от автоматического пропуска опенингов и таймлайна с выделением OP/ED до прямой загрузки серий и авторизации в Shikimori.

## ( ✦ ) Сравнение с оригинальным AniDesk

| Функция / Возможность | Оригинальный AniDesk | AniDesk Plus |
| :--- | :---: | :---: |
| **Скачивание серий** | ❌ Отсутствует | **Прямая загрузка MP4/MKV** с выбором качества |
| **Интеграция с Shikimori** | ❌ Отсутствует | **GraphQL & OAuth2**, автотрекинг серий, списки |
| **Таймлайн и пропуск OP/ED** | ❌ Отсутствует | **AniSkip + Kodik parser**, сегменты на таймлайне |
| **Запоминание позиции просмотра** | ❌ Отсутствует | **Точное сохранение таймингов** для каждого эпизода |
| **Приоритетные озвучки** | ❌ Отсутствует | **«Колокольчик» озвучек** и фильтрация уведомлений |
| **Работа в фоне / Трей** | ❌ Отсутствует | **Сворачивание в трей** и фоновые уведомления |

### ( 📥 ) Загрузка серий
Скачивайте любимые эпизоды напрямую на ПК. Поддерживается выбор источников (`Kodik`, `AniLibria`, `Sibnet`), выбор качества (1080p / 720p / 480p) и сохранение с форматированным именем файла.

### ( 🌸 ) Интеграция с Shikimori
- Авторизация через официальный OAuth2.
- Автоматическая синхронизация статусов просмотра (*Смотрю*, *Просмотрено*, *В планах*, *Брошено*).
- Автоматическое обновление просмотренных серий при воспроизведении в плеере.
- Выбор зеркал API (`shikimori.io`, `shikimori.me`, `shikimori.one`) и автоматическое продление токенов.

### ( ⏩ ) Таймлайн и автопропуск OP/ED
- Визуальное выделение полупрозрачных сегментов опенингов и эндингов прямо на шкале прогресса.
- Парсинг таймингов из баз **AniSkip**, **AniLibria** и плеера **Kodik**.
- Настраиваемые уведомления и автопропуск.

### ( ⏱️ ) Запоминание позиции просмотра
Приложение запоминает точное время остановки для каждого эпизода и отображает полосу прогресса в списке серий.

## ( 📦 ) Установка и сборка

### Готовые сборки
Скачайте установочный файл `.exe` на странице [**Releases**](https://github.com/MjKey/AniDeskPlus/releases).

### Сборка из исходного кода

Для самостоятельной сборки потребуется [Node.js](https://nodejs.org/) (v18+) и [Git](https://git-scm.com/):

```bash
# 1. Клонирование репозитория
git clone https://github.com/MjKey/AniDeskPlus.git
cd AniDeskPlus

# 2. Установка зависимостей
npm install

# 3. Запуск в режиме разработки
npm run dev

# 4. Сборка готового дистрибутива
npm run buildAndMake
```
